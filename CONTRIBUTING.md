# Mitarbeit & Branching-Strategie

Dieses Repository folgt dem **GitHub Flow**:
- Der Branch `main` ist stets stabil und auslieferbar.
- Jede Änderung erfolgt über einen kurzlebigen Branch (`feature/`, `fix/`, `docs/`).
- Vor dem Merge in `main` muss ein Pull Request erstellt werden.
- Commit-Messages folgen den Conventional-Commit-Konventionen (z. B. `feat:`, `fix:`, `docs:`).
